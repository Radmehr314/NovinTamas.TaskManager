# NovinTamas.TaskManager

میکروسرویس مدیریت وظایف (تسک‌منیجر) شرکت‌ها در سامانه‌ی نوین‌تماس.

هر شرکت فضای کاری مستقل خودش را دارد: پروژه‌ها، وظایف، چک‌لیست، گفتگو، تاریخچه‌ی فعالیت و اعلان.
مدیر شرکت از پنل مدیریت کار می‌کند و پرسنل از پنل کاربری.

## معماری

Clean Architecture با CQRS، دقیقاً منطبق بر بقیه‌ی میکروسرویس‌های نوین‌تماس:

| پروژه | نقش |
| --- | --- |
| `Domain` | موجودیت‌ها، enumها و اینترفیس مخزن‌ها؛ بدون وابستگی بیرونی |
| `Application.Contracts` | Commandها، Queryها، QueryResultها و اینترفیس سرویس‌های بیرونی |
| `Application` | هندلرهای Command/Query و قواعد دسترسی |
| `Infrastructure.Persistance` | مخزن‌های MongoDB، سرویس‌های HTTP و RabbitMQ، کارهای پس‌زمینه |
| `Infrastructure.Config` | ثبت وابستگی‌ها در Autofac |
| `Api` | کنترلرها، احراز هویت JWT، rate limiting و Swagger |

- **پایگاه داده:** MongoDB، دیتابیس `NovinTamas_TaskManager`
- **صف پیام:** RabbitMQ با الگوی Outbox برای انتشار رویدادها
- **دات‌نت:** ‎.NET 10

## مرز چندمستاجری

`companyId` مرز جداسازی داده‌هاست و از توکن JWT خوانده می‌شود:

- مدیر شرکت (`role = user`): خودِ `userId` نقش `companyId` را دارد
- پرسنل (`role = employee`): `companyId` در claim جداگانه می‌آید

هر کوئری مخزن با `companyId` فیلتر می‌شود؛ هیچ endpointای شناسه‌ی شرکت را از بدنه‌ی درخواست نمی‌پذیرد.

## دسترسی‌های پرسنل

مدیر شرکت برای هر پرسنل این چهار دسترسی را جداگانه تعیین می‌کند:

| دسترسی | پیش‌فرض | اثر |
| --- | --- | --- |
| `CanCreateTask` | فعال | ساخت وظیفه برای خودش |
| `CanCreateForOthers` | غیرفعال | انتخاب همکاران به‌عنوان مسئول هنگام ساخت |
| `CanAssignToOthers` | غیرفعال | تغییر مسئولین وظایف موجود |
| `CanViewOthersTasks` | غیرفعال | دیدن همه‌ی وظایف شرکت، نه فقط وظایف خودش |

ویرایش کامل و حذف وظیفه همیشه فقط برای مدیر شرکت و سازنده‌ی وظیفه مجاز است.

## امکانات

- برد کانبان با ۵ ستون و مرتب‌سازی دستی کارت‌ها
- پروژه‌ها با رنگ اختصاصی و درصد پیشرفت
- چک‌لیست با محاسبه‌ی خودکار درصد پیشرفت وظیفه
- گفتگو و پیوست فایل روی هر وظیفه
- تاریخچه‌ی کامل تغییرات همراه با IP و User-Agent
- اعلان درون‌برنامه‌ای برای ارجاع، تغییر وضعیت و نظر جدید
- یادآور خودکار مهلت (هر ۳۰ دقیقه) برای وظایف نزدیک‌مهلت و عقب‌افتاده
- گزارش بار کاری تیم، توزیع اولویت و مهلت‌های پیش‌رو

## اجرای محلی

```bash
dotnet run --project NovinTamas.TaskManager.Api --urls http://localhost:5090
```

Swagger در محیط توسعه روی `/swagger` در دسترس است.

تنظیمات در `NovinTamas.TaskManager.Api/appsettings.json` قرار دارد: رشته‌ی اتصال Mongo،
کلید امضای JWT، مشخصات RabbitMQ و آدرس سرویس‌های IAM و UserProfile.

## استقرار

```bash
dotnet publish -c Release -o <output>
```

سرویس پشت nginx با prefix `/taskmanager` سرو می‌شود و روی پورت `8008` گوش می‌دهد.
